# 📚 Книжная полка

**Трекер чтения: цель на год, темп, прогноз окончания книги, полка прочитанного и цитаты.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/bookshelf/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Статусы «Читаю / Хочу / Прочитано»
- Прогноз даты окончания по вашему темпу
- Полка с корешками по годам
- Оценки и цитаты, цитата дня
- Цель на год с кольцом прогресса

## Стек

JavaScript. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/bookshelf.git
cd bookshelf
python3 -m http.server 8000
```
